# HERMES-01 domain contract (version 1)

`PuppeteerStore(SocialStore)` adds `puppeteer/migrations/001.sql` to the existing SQLite authority. No parallel world identity/database. Config hash covers the versioned recap policy and authored personas; model selection does not invalidate game memory. Migration gives legacy saves a zero puppeteer cutoff. Explicit activation starts a new mandatory-recap boundary without historical backfill. Legacy SOCIAL writers refuse migrated databases.

The append-only puppeteer log retains ACTIVATED, RECAP_REQUIRED, GENERATING, EPISODE, PUBLISHED and director-only SOCIAL_LINK references. Semantic IDs use campaign/branch/battle/actor, not model requests. Jobs and epochs are control state; operator audit is append-only and excluded from actor retrieval. Unsupported confirmed outcomes are explicitly audited. Supported normal single-trainer win/loss/draw native outcomes are 1/2/3; wild/unfinished encounters have no recap. Unsupported multi/opponent modes retain the existing WORLD rejection boundary. No new rematch unlock is implemented.

`schemas/hermes_recap_v1.json` describes the processing proposal. Domain validation additionally checks every reference against the granted actor, completed battle, active branch and pinned cutoffs. Public references must contain the confirmed result and only approved result/seen-species claims; max two. Private references retain announced player actions and the participant's own actually announced moves, max sixteen. No raw HP, PP, hidden party, unannounced moves, arbitrary prose, confidence, tendency or recipients. NPC action evidence is selected from the existing pinned `PiEvents_Action` exporter, restricted to side 1 and announced_move, not an unrestricted event dump.

An EPISODE contains actor/battle/obligation/post IDs; actor_private visibility; campaign/branch/world/memory/social/puppeteer cutoff; source and public evidence IDs; prior episode IDs; template/tone; deterministic concise outcome/seenSpeciesIDs/observedPlayerMoves/ownAnnouncedMoves; schema/prompt/model/producer metadata. The model selects evidence and style references. Public prose and the private factual summary are deterministically rendered. The canonical history remains unchanged.

The same transaction commits the existing SOCIAL post/decision, private episode and authoritative PUBLISHED outcome. Publication creates established durable distribution work; `tick` schedules configured feeds. Exposure invokes the existing MEMORY delivery service. SOCIAL_LINK records director-only delivery/exposure references. Publication, unread feed, exposure and retained recipient claims remain distinct.

`TrainerKnowledgePacket` version 1 is queried using `trainer_packet(actor)`: identity, authored persona, exact cutoff/epochs, direct observations, attributed exposed claims, actor-owned retained episodes, seen species, explicit unknowns, truncation and bounded observedChanges between owned episodes. Differences describe newly observed species/moves, never a claim that an omitted move disappeared or a broad player tendency. strategicInterpretation is null. Janice is built from her receipts, never from Rick's private/director summary. Doug has no qualifying evidence. Director retrieval is a separate trusted host method, never a model tool.

Read-only memory inspection grants bind one existing actor and episode timeline; they cannot submit another recap. They support fresh-process continuity checks without manufacturing an encounter or republishing a completed obligation.

Each paired save gains a fourth cutoff and replay hash. Restores revoke active jobs and rewind episodes/obligations/social links; future rows remain historical but inaccessible. Host-only work after an older restore forks before publication. Commit rechecks branch/epochs/cutoffs/save barrier and obligation state. Expired, absent, malformed, refusal or NO_POST output selects a factual fallback for the same logical obligation. Late output cannot rewrite published claims. Recovery either settles fallback or revokes the grant and records an explicit evidence/timeline recovery state. No missing evidence is fabricated.
