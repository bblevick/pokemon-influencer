# Reference records

These synthetic records illustrate one coherent branch: first battle, Boulder Badge, prepared rematch, training post, delivery, and a later battle observation. Reed is an illustrative unbound profile, not a claim about a vanilla trainer ID. The local contact is an external example reference, not a fully authored profile.

The schema and handoff checker validate structure and selected cross-record invariants. They do not implement a ROM adapter, full species/move catalog, battle simulator, real social graph, or event engine. The final production observation will also need the complete permitted own-team battle fields, status/phase details, and generated wire layout.

Source-derived FireRed legality must be revalidated after Phase 0 pins the actual game data. The reference evolution/retained-move example is a design candidate, not a completed emulator test.
