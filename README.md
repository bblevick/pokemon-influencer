# Pokemon Influencer

Standalone source snapshot of the Pokemon Influencer workspace.

- [`pokefirered/`](pokefirered/): modified FireRed source, host runtime, configuration, tests, documentation, and retained non-private verification evidence. Start with [`docs/status.md`](pokefirered/docs/status.md) for current acceptance and readiness.
- [`agbcc/`](agbcc/): adjacent compiler source; original licenses and notices retained.
- [`PUBLICATION.json`](PUBLICATION.json): source revision provenance and file hashes for this export.

Local ROMs (including upstream binary `.gba` payloads), saves, credentials, private evidence, local databases, emulator/runtime installations, and generated build products are intentionally omitted. Obtain necessary proprietary inputs locally and follow the pinned project build instructions; this repository is not a runnable ROM distribution. Some retained evidence references omitted local artifacts.

This snapshot includes the current working-tree implementation, not just the original upstream revision. Upstream source licensing/notices continue to apply; no new license is asserted over third-party game content. Hosted inference remains disabled, and publication does not advance campaign acceptance.
